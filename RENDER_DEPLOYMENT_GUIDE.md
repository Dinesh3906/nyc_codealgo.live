# PermitIQ by Aureon — Render Migration & Deployment Guide

This guide details the complete transition from AWS (EC2 + Route 53) to **Render** for hosting the PermitIQ platform.

---

## 1. Why Switch to Render?

| Feature | AWS (Previous) | Render (New) |
|---|---|---|
| **Server Management** | Manual EC2 patching, SSH keys, security groups | Fully managed serverless containers |
| **Process Manager** | Manual PM2 restarts (`ecosystem.config.js`) | Automatic zero-downtime healthcheck & auto-restart |
| **CI/CD** | Custom bash/SSH deploy scripts | Automatic git push deploys (`main` branch) |
| **SSL / HTTPS** | Manual certbot / ACM setup | Free, automatic Let's Encrypt SSL with auto-renewal |
| **Storage** | Local disk / manual S3 bucket setup | 10GB attached persistent disk at `/app/uploads` |
| **DNS / Routing** | Route 53 hosted zones (prone to lame delegation) | Standard CNAME records directly to `.onrender.com` |

---

## 2. Infrastructure as Code: `render.yaml`

The repository includes a ready-to-use Render Blueprint ([render.yaml](file:///d:/nyc_algo/render.yaml)) defining two primary services:

### A. `permitiq-api` (Backend Web Service)
* **Runtime:** Node 20
* **Root Directory:** `backend`
* **Build Command:** `npm install && npm run build`
* **Start Command:** `npm start`
* **Health Check Path:** `/health`
* **Disk:** Attached 10GB persistent disk mounted at `/app/uploads`
* **Port:** `10000` (automatically mapped by Render)

### B. `permitiq-web` (Frontend Web Service)
* **Runtime:** Node 20
* **Root Directory:** `frontend`
* **Build Command:** `npm install && npm run build`
* **Start Command:** `npm start`
* **Port:** `3000` (or dynamic `$PORT`)

## 3. Step-by-Step Deployment (1-Click Blueprint)

### Step 1: Open Render Dashboard
1. Log in to [dashboard.render.com](https://dashboard.render.com).
2. Click **New +** in the top right corner and select **Blueprint**.

### Step 2: Connect Repository
1. Select your GitHub repository: `Dinesh3906/nyc_codealgo.live`.
2. Render will automatically detect [render.yaml](file:///d:/nyc_algo/render.yaml).

### Step 3: Enter Required Secrets
Render will prompt you for the required environment variables:

| Environment Variable | Description | Example / Note |
|---|---|---|
| `DATABASE_URL` or `DB_HOST` | Database connection string | `mysql://user:pass@host:3306/permitiq` |
| `DB_USER`, `DB_PASS`, `DB_NAME` | Alternative to `DATABASE_URL` | Used if connecting to MySQL/TiDB directly |
| `GOOGLE_AI_STUDIO_KEY` | Gemini API key | Google AI Studio Key |
| `PINECONE_API_KEY` | Vector search API key | Pinecone console key |
| `GROQ_API_KEY` | LLM parsing key | Groq API key |
| `GOOGLE_CLIENT_ID` | OAuth Client ID | Google Cloud Console |
| `GOOGLE_CLIENT_SECRET` | OAuth Client Secret | Google Cloud Console |
| `RAZORPAY_KEY_ID` | Razorpay Live Key ID | `rzp_live_...` |
| `RAZORPAY_KEY_SECRET` | Razorpay Live Secret | Razorpay dashboard |
| `JWT_SECRET` | Auth signing secret | Auto-generated by Render |
| `METRICS_API_KEY` | Prometheus & health metric key | Auto-generated by Render |

### Step 4: Click "Apply"
Render will provision both the backend and frontend services, install dependencies, compile TypeScript, run the Next.js production build, and bring both services online.

## 4. Triggering Deployments from Local Machine

Whenever you make changes, run the new deployment script:

```powershell
# In PowerShell:
.\deploy_render.ps1 -CommitMessage "feat: your new feature"
```

Or using Git Bash:
```bash
./deploy_render.sh "feat: your new feature"
```

Because Render listens to GitHub commits on `main`, pushing to the repository will automatically build and deploy your application.

## 5. Custom Domain Setup (`codealgo.live`)

Once your services are deployed on Render:

1. **Backend Domain (`api-permitiq.codealgo.live`)**:
   * In your Render dashboard, navigate to `permitiq-api` > **Settings** > **Custom Domains**.
   * Add: `api-permitiq.codealgo.live`.
   * In your domain DNS registrar (e.g., Namecheap, Cloudflare, GoDaddy):
     * Create a **CNAME** record:
       * **Name / Host:** `api-permitiq`
       * **Value / Target:** `permitiq-api.onrender.com`

2. **Frontend Domain (`permitiq.codealgo.live`)**:
   * In your Render dashboard, navigate to `permitiq-web` > **Settings** > **Custom Domains**.
   * Add: `permitiq.codealgo.live`.
   * In your domain DNS registrar:
     * Create a **CNAME** record:
       * **Name / Host:** `permitiq`
       * **Value / Target:** `permitiq-web.onrender.com`

Render will automatically issue SSL certificates (via Let's Encrypt) within minutes.

## 6. Verifying the Deployment

Run health checks against the live endpoints:

```bash
# 1. Liveness Probe (HTTP 200)
curl -I https://permitiq-api.onrender.com/health

# 2. Readiness Probe (Checks database & vector store connectivity)
curl -I https://permitiq-api.onrender.com/ready
```
